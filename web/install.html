Put NOST4LGIA on your TV

Nost4lgia runs as a native app on LG webOS TVs (built for a 2020 UN7000 on webOS 5, but it should work on any webOS TV with Developer Mode). It sideloads as an .ipk — no SDK, no App Store.

Just want to look around first? You don't need a TV — the browser guide runs the same channels right here. This page is for installing the full remote-driven app onto an LG TV.

1Enable Developer Mode on the TV

  1. Install the Developer Mode app from the LG Content Store (a free LG account is required).
  2. Open it, sign in, and switch Dev Mode Status on — the TV reboots.
  3. Turn on Key Server. Note the IP address and passphrase it shows.

2Install the tooling on your computer

You'll need Node.js 18+, Python 3 with Pillow (pip install pillow), and LG's CLI:

npm install -g @webosose/ares-cli

Register your TV (use the IP from step 1; enter the passphrase when prompted):

ares-setup-device --add tv --info "host=<TV_IP> port=9922 username=prisoner"
ares-novacom --device tv --getkey

Replace <TV_IP> with your TV's address, e.g. 192.168.0.208.

3Get the code and build it

git clone https://github.com/nicolascribbles/nost4lgia.git
cd nost4lgia

node nost4lgia-src/build_channels.js   # writes launcher/spelunkr-channels.js
python build_ipk.py                    # writes dist/tv.livingroom.shell_<ver>_all.ipk

The first command fetches the channel lineup and bakes it into a local data file; the second packages the app into an installable .ipk.

4Install and launch

ares-install --device tv dist/tv.livingroom.shell_2.5.1_all.ipk
ares-launch  --device tv tv.livingroom.shell

Nost4lgia opens on the TV. Drive it with the remote: ▲▼ change channel, ◀▶ browse the guide, OK to watch, 0–9 to tune by number, Back to step out.

5One-button access (optional)

webOS won't let an app take over the physical Home button, but you can long-press a number key (1–9) on the LG remote and assign the Living Room app as a shortcut — then that number jumps straight in.

Heads up: dev-mode apps stay installed only while Developer Mode is active. LG requires periodic renewal from inside the Dev Mode app.
